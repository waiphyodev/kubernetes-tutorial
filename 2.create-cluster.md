# Create Cluster

## Create a cluster with `kind`

### 1. Create a `cluster.yaml` file

```yaml
kind: Cluster
apiVersion: kind.x-k8s.io/v1alpha4
nodes:
- role: control-plane
- role: worker
- role: worker
networking:
  disableDefaultCNI: false
```

### 2. Create cluster as root using `kind create cluster`

#### input

```bash
sudo kind create cluster --config cluster.yaml -n demo
```

#### output

```bash
enabling experimental podman provider
Creating cluster "agb" ...
 ✓ Ensuring node image (kindest/node:v1.29.4) 🖼 
 ✓ Preparing nodes 📦 📦 📦  
 ✓ Writing configuration 📜

You can now use your cluster with:

kubectl cluster-info --context kind-demo

Not sure what to do next? 😅  Check out https://kind.sigs.k8s.io/docs/user/quick-start/
```

### 3. Before anything go further, we need to print out the "demo" cluster `kubeconfig`

#### input

```bash
mkdir ~/.kube
sudo kind get kubeconfig -n demo > ~/.kube/config
kubectl get nodes
```

#### output

```bash
NAME                STATUS   ROLES           AGE   VERSION
demo-control-plane   Ready    control-plane   23h   v1.29.4
demo-worker          Ready    <none>          23h   v1.29.4
demo-worker2         Ready    <none>          23h   v1.29.4

```

As we declare in `yaml` file, the cluster is running with 2 worker nodes.
